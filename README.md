## About this mod

Better Inventory Management 9minecraft Mod upgrades your inventory controls by adding handy mouse shortcuts for moving and sorting items. This mod lets you drag items across slots, pull matching items with a single sweep, and transfer stacks using the scroll wheel. It operates on the client side, making item management quick inside chests, furnaces, and crafting tables. Features: Holding the right mouse button while dragging drops one item into each slot, even over existing items.
